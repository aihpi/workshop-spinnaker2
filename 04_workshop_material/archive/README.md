# Archive

Earlier versions of workshop notebooks that the current workshop no longer uses, kept for reference.

- `02_synfire_chain.ipynb`: the former hands-on 2 (a synfire chain of five neuron groups), replaced on 2026-11-17 by `02_direction_detector.ipynb`. Its links to the workshop notes assume the notebook sits in `04_workshop_material/`; copy it there to run it.
- `03_nir_minimal.ipynb`: the former first notebook of hands-on 3 (a small snnTorch network, exported to NIR and checked spike for spike), replaced on 2026-11-17 by `03_direction_nir.ipynb`.
- `04_nir_end_to_end.ipynb`: the former second notebook of hands-on 3 (a network trained in snnTorch to reproduce the SpiNNaker2 logo as a spike pattern), replaced on 2026-11-17 by `04_direction_trained.ipynb`. It loads `data/scattered_logo.npy`, which moved here with it (sources in `data/README.md`); run it from this folder.
